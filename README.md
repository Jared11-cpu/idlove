# idlove

A small painted world: a seaside garden, a few places to wander, and a letter.
Static site (HTML, CSS, JavaScript, WebP images). No build step.

Run locally:

    python -m http.server 5186

Then open http://127.0.0.1:5186

Text lives in `js/content.js` (letter and notes) and `js/experience-copy.js` (interface). Places and clickable spots are in `js/chapters.js`.
